# Awarding Mythic 3.0

Slide awarding berbasis HTML: satu file `index.html`, kontrol panah kanan/kiri, F untuk layar penuh.

- Data juara: bagian `EVENT` di atas script `index.html`.
- Suara: `audio/` (drumroll, fanfare, fanfareShort, applause). Kalau file tidak ada, dipakai suara sintetis (Web Audio).
- Lompat ke slide saat latihan: `index.html#4`.

## Kredit suara (Wikimedia Commons, domain publik)
- drumroll: "Drum Roll - Concert Band", United States Air Force Band
- fanfare: "Four Ruffles and Flourishes ... Hail To The Chief", US military band
- applause: "Applause i"
